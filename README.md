# Mushroom Database: การสำรวจเห็ดเขาหลวง

เว็บไซต์นี้สร้างขึ้นเพื่อใช้เป็นสื่อประกอบโครงงานวิทยาศาสตร์เรื่อง "การสำรวจความหลากหลายของเห็ดตามเส้นทางศึกษาธรรมชาติเขาหลวง" โดยแสดงข้อมูลจาก 7 รอบการสำรวจในรูปแบบที่เข้าใจง่ายและเหมาะสมกับการนำเสนอ

## โครงสร้างข้อมูล

- ข้อมูลดิบถูกแปลงจากไฟล์ Excel 1.xlsx ถึง 7.xlsx ด้วยสคริปต์ Python
- ผลลัพธ์ถูกสร้างเป็นไฟล์ JSON ที่เก็บไว้ในโฟลเดอร์ data/
- ภาพจากคอลัมน์ภาพใน Excel ถูก export เป็นไฟล์รูปภาพใน public/images/

## วิธีรัน

```bash
npm install
npm run dev
```

เปิดบราวเซอร์ที่ http://localhost:3000 เพื่อดูเว็บไซต์

## หน้าเว็บที่มี

- หน้าแรก: แผนที่เส้นทางศึกษาธรรมชาติ + ตัวเลือกรอบการสำรวจ
- หน้าแต่ละรอบ: รายการชนิดเห็ดพร้อมการค้นหาและกรองข้อมูล
- สรุปสภาพอากาศเฉลี่ยของแต่ละรอบ
